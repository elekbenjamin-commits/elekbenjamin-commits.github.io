Privacy Policy — Rclone Backup

Rclone Backup is a personal-use configuration of the open-source rclone program. This notice describes the account owner's Google Drive backup workflow.

Data accessed

The program accesses file and folder names, metadata, and file contents from the Google Drive account explicitly authorized by its owner. The connection uses read-only Google Drive permission.

Purpose of access

The data is read only to create and update a backup. Google Docs, Sheets, and Slides may be exported to common offline file formats.

Storage and retention

Backup copies are stored on the owner's locally connected external drive. They remain there until the owner deletes or replaces them. Earlier versions and copies of files deleted from Google Drive may be retained locally as part of the backup process.

Sharing and transmission

This configuration does not send Google Drive file contents to a separate application-operated server, analytics provider, or advertiser. Data is retrieved from Google's service directly by the rclone software running on the owner's computer. This public website is hosted by GitHub Pages and contains no backup files or OAuth credentials.

Access and control

Only the account owner operates the backup. Google access can be revoked in the Google Account's third-party connections settings. Stored backups can be deleted from the owner's external drive.

Website

This informational site has no form, cookies set by the application, analytics scripts, or sign-in facility. The hosting provider may process standard web request data under its own policies.
